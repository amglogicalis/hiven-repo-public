Guía de Arquitectura & Documentación Técnica

1. Visión General

Hiven es el agente de ingeniería de software autónomo multi-agente de coste \$0 del ecosistema Terra. Funciona transformando los runners efímeros de GitHub Actions en un laboratorio de desarrollo neuronal coordinado.

2. Pipeline de 4 Fases

El enjambre ejecuta un proceso estricto y determinista:

  • Fase 0 (Deterministic Extractor): Inspecciona dependencias y AST sin alucinaciones.
  • Fase 1 (Architect): Descompone la misión en un grafo acíclico de tareas (Task DAG).
  • Fase 2 (Parallel Coders): Nodos Kōmbee concurrentes escriben código usando bloques de búsqueda y reemplazo.
  • Fase 3 (Shadow Sandbox): Ejecuta tests unitarios en un contenedor aislado previo a cualquier commit.
  • Fase 4 (Consolidator): Consolida los parches ganadores y crea la Pull Request oficial.

3. Bucle de Auto-Sanación (Self-Healing Loop)

Si la Fase 3 detecta que los tests fallan, Hiven extrae el stack trace de error y lo reinyecta automáticamente en un sub-enjambre de corrección (hasta 3-5 intentos) hasta que la suite de pruebas concluya con éxito.

7. Preguntas Frecuentes (FAQ)

¿Hiven tiene algún coste de infraestructura mensual?

No. Opera 100% sobre minutos gratuitos de GitHub Actions, almacenamiento en repositorios Git y GitHub Pages.

¿Dónde se almacena la memoria Honeycombs?

Se almacena en tu propio repositorio privado .hiven-storage y en la memoria local de sesión.

🔑 Configuración de GitHub Personal Access Token (PAT)

Introduce tu token para conectar la Consola Web con tus repositorios de GitHub. Se almacena exclusivamente en tu navegador.

Permisos requeridos: repo y workflow.
